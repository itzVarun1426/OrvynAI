# End-to-End Product Flow

```
1. Landing / Authentication
   ├── Register with OTP verification (Resend)
   └── Login & Profile Setup

2. Candidate Input (Dashboard)
   ├── Resume Upload (PDF)
   └── Job Description Input (Text)

3. Candidate & Job Deep Analysis
   ├── Candidate profile extraction (Skills, Frameworks, Projects)
   ├── Job requirement extraction (Required, Preferred)
   ├── Evidence-based skill comparison (Strong, Moderate, Weak)
   └── Compact visual Interview Plan generation

4. Interview Session (Adaptive Interview Room)
   ├── Audio/Video hardware check
   ├── Initial question based on plan
   ├── Candidate speaks answer (Live Speech-to-Text & Audio Recording)
   ├── Immediate Answer Evaluation (Depth, Correctness, Trade-offs)
   ├── Dynamic Follow-up / Challenge Mode / Difficulty Adjustment
   └── Project Deep-Dive questions (Architecture, Scalability, Failure scenarios)

5. Actionable Final Report (Modern SaaS Dashboard)
   ├── Overall Score & Recommendation
   ├── Category Score Breakdown (Technical Knowledge, Problem Solving, Communication, Project Understanding, System Design, Role Readiness)
   ├── Skill Heatmap with proficiency levels
   ├── Job Readiness assessment
   ├── Strengths & Weaknesses (with specific evidence from answers)
   ├── Interactive Question-by-Question Review with "Why was I asked this?"
   ├── Personalized 7-Day Preparation Plan
   └── [ Practice My Weak Areas ] & Question Retry
```
