# Resume and Job Description Analysis

## Profile Extraction
When a candidate uploads a PDF resume and pastes a Job Description:
- **Candidate Profile**:
  - Technical skills (Languages, Frameworks, DBs, Cloud/DevOps)
  - Key projects (Titles, Architectures, Claims made)
  - Experience and education background
- **Job Description Analysis**:
  - Core required competencies
  - Preferred bonuses
  - Primary responsibilities
- **Skill Gap Matrix**:
  - Direct comparative matrix with status (`Strong`, `Moderate`, `Weak`) and evidence from resume text.
- **Compact Interview Plan**:
  - Breakdown across 5 core categories: Technical Fundamentals, Project Deep Dive, Role-Specific Skills, Problem Solving, and Behavioral.
