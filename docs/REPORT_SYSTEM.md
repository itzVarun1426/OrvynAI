# Visual Report System

## Dashboard Layout
- **Hero Header**: Role title, date, questions completed, overall score (0-100), key headline summary.
- **Score Breakdown**:
  - Technical Knowledge
  - Problem Solving
  - Communication
  - Project Understanding
  - System Design
  - Role Readiness
- **Visual Skill Heatmap**:
  - Horizontal proficiency indicators & radar distribution.
- **Job Readiness Card**: Readiness percentage with prioritized study items.
- **Strengths & Weaknesses**: Concrete evidence linked to specific interview questions.
- **Question-by-Question Accordion**: Includes "Why was I asked this?" badge and modal context.
- **7-Day Personalized Preparation Plan**: Tailored daily schedule.
- **Action Bar**: "Practice My Weak Areas" button triggering targeted mini-session.
