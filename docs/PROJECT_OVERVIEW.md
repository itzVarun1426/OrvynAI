# intervAI Project Overview

## Vision
To provide candidates with a realistic technical interview experience that mirrors top-tier engineering interviews:
1. **Evidence-based Profile Parsing**: Extracts skills, projects, and claims from PDF resumes.
2. **Target Role Alignment**: Analyzes Job Descriptions for requirements, preferred skills, and expectations.
3. **Skill Gap Diagnostics**: Cross-examines candidate claims against JD requirements.
4. **Adaptive Interview Flow**: Dynamically adjusts difficulty (Beginner, Intermediate, Advanced, Expert) and dives into project architecture and trade-offs.
5. **Challenge Mode**: Actively detects surface-level buzzwords and asks clarifying, probing questions.
6. **Actionable Analytics**: Professional SaaS report with heatmaps, role readiness, breakdown, and 1-click weak-area practice.
