# Adaptive Interview Mechanics

## Dynamic Difficulty Ladder
```
Beginner ──(Strong)──> Intermediate ──(Strong)──> Advanced ──(Strong)──> Expert
   ▲                        │                     │
   └───(Struggling)─────────┴────(Struggling)─────┘
```

## Probing and Challenge Mode
- Detects buzzword claims (e.g. "scalability", "microservices", "blockchain", "caching").
- Formulates follow-up queries referencing candidate words directly: "You mentioned using Redis for caching. What specific keys or invalidation strategy did you deploy?".
- Keeps demeanor respectful, professional, and rigorous.
