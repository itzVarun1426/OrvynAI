# AI Evaluation Architecture

## Evaluation Rubric
Answers are evaluated across multiple qualitative dimensions rather than arbitrary right/wrong binary:
- **Technical Accuracy**: Does the explanation reflect correct technical principles?
- **Depth & Reasoning**: Did the candidate explain *why*, or just repeat definitions?
- **Trade-off Awareness**: Did the candidate address performance, memory, operational costs, or architectural implications?
- **Direct Feedback Structure**:
  - `What you did well`
  - `What was missing`
  - `How to improve`
  - `Stronger answer`
  - `Likely follow-up question`
